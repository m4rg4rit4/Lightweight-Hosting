# 🚀 Lightweight-Hosting

**Sistema de hosting ultra-ligero** diseñado para hardware extremadamente limitado (1vCore, 1GB RAM) ejecutándose sobre **Debian 13**.

Este componente es el núcleo del ecosistema **Lightweight**.
